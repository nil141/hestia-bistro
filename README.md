# Hestia Bistró — Web

Cocina de autor en Igualada. Sitio estático (HTML + CSS + JS).

## Estructura

- `index.html` — página única
- `styles.css` — estilos
- `script.js` — interacciones (carrusel, scroll fade, nav)
- `assets/` — imágenes, logo SVG, fuentes (Dahlia, Barlow)

## Deploy

Conectado a Netlify desde este repo. Cada push a `main` dispara un build automático.

## Stack

- HTML estático
- Tipografías: Dahlia Display (títulos), Barlow (cuerpo), La Belle Aurore + Italiana + Cormorant Garamond (acentos)
- Sin build step
